Demonstrate that you understand the major instructional design models well enough to compare them and to choose one for a real problem.

## Part A: Comparison matrix (25 points)

Build a matrix comparing **four** models: ADDIE, Dick and Carey, SAM, and one more of your choice (Kemp, Backward Design, rapid prototyping, or another documented model). For each model, complete these rows in your own words, citing the module readings or the original sources:

| Row | What to include |
| --- | --- |
| Origin | Author(s), year, and the problem the model was created to solve |
| Process shape | Linear, circular, iterative; where evaluation sits |
| Key assumptions | What the model assumes about learning, learners, and the design context |
| Distinctive strength | The one thing this model does better than the others |
| Distinctive weakness | The one thing it does worse, or the situation it handles poorly |
| Best-fit project | A concrete example of a project you would use it for, in one sentence |

## Part B: Model selection memo (25 points)

Write a memo of 600 to 800 words to a hypothetical client or supervisor recommending a model (or a justified hybrid) for your course design project problem. The memo must:

1. State the instructional problem in one paragraph: learners, gap, setting, constraints.
2. Answer the four model-selection questions from the models page explicitly.
3. Recommend a model or hybrid and describe how the project would proceed under it, phase by phase, in a short table or list.
4. Name one model you rejected and explain what feature of the problem ruled it out.
5. Identify one risk of your chosen approach and how you would mitigate it.

## Submission

One PDF or Google Doc link containing both parts. APA 7 citations and a reference list. Add an AI-use disclosure line at the end if applicable.
